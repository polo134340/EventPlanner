# Event Planner (React + Vite)

A personal event planner that allows users to register/login and manage events (add, edit, delete) using React, React Router, and the Context API.

## Features
- Register (name, email, username, password) with validation
- Login + protected routes
- Dashboard showing events (upcoming/all) with search
- Add / Edit / Delete events (updates immediately)
- Fixed header navigation (Dashboard, Add Event, Help)
- Responsive layout for desktop/mobile
- Local persistence using localStorage

## Tech
- React
- Vite
- React Router
- Context API
